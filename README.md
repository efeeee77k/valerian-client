# Valerian Client

Lightweight utility client for Minecraft 1.21.11 (Fabric).

**Features planned:**
- Hitbox
- Name Protect / Skin Protect
- Sprint
- Swing Speed (visual)
- Chat Keybind
- Friends system
- Draggable HUD (FPS, Coordinates, Armor, Keystrokes, Potion Effects, Ping, Direction, Target HUD)

**Menu:** Right Shift (changeable)

Made for both PC and Mojo Launcher (Android).
